Professional AI chat assistant featuring website knowledge sync, multimodal analysis, chat summarization, lead alerts, and CSV data export.

== Description ==

AICA IntelliAgent is a next-generation AI solution that transforms WordPress sites into interactive knowledge hubs. By combining advanced scraping and document parsing with flagship LLM models (GPT-5.2, Gemini 3, Grok 4), it provides factual, context-aware answers 24/7.

**Key Intelligence Features:**

* **Smart Scraper & Sync:** Automatically crawls and synchronizes site content into the AI knowledge base.
* **Multimodal Analysis:** Analyzes PDFs, TXT files, and Images to provide grounded responses.
* **AI Summarize & Analytics:** One-click summarization of chat logs to quickly identify lead intent.
* **Interactive Chat Tools:** Built-in "Copy to Clipboard" for users and "Feedback Buttons" to measure AI quality.
* **Lead Generation:** Automated email notifications for admins when users interact with the agent.
* **Data Portability:** Export full conversation histories in CSV format for CRM use.

== Installation ==

1. Upload the `aica-intelliagent` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin via the 'Plugins' menu.
3. Access **AICA Agent > Settings** to input your API keys (OpenAI, Gemini, or Grok).
4. Run "Discovery" in the Knowledge Base tab to sync your site content.

== Frequently Asked Questions ==

= Can I export my chat data? =
Yes, you can export all chat logs into a standard CSV format directly from the plugin dashboard.

= How do I know if the AI is accurate? =
The plugin includes feedback buttons (Thumbs Up/Down) on every AI response. You can monitor user sentiment in your admin logs.

= Does it support email alerts? =
Yes, you can configure an admin email to receive notifications for new conversations.
