An advanced AI-powered chat assistant featuring automated website knowledge synchronization, document analysis (PDF/TXT), and support for flagship models like GPT-5.2, Gemini 3, and Grok 4.

== Description ==

AICA IntelliAgent is a professional-grade AI solution for WordPress that turns your website into an intelligent knowledge base. Unlike standard chatbots, IntelliAgent uses RAG (Retrieval-Augmented Generation) to learn from your existing pages and uploaded documents to provide factual, brand-specific responses.

**Key Features:**

* **Automated Website Sync:** Scrapes and synchronizes your WordPress pages into the AI's knowledge base.
* **Document Intelligence:** Upload PDFs or Text files that the AI can reference during conversations.
* **Multi-LLM Support:** Choose between OpenAI (GPT-5.2), Google Gemini 3, or xAI Grok 4.
* **Modern Interface:** A sleek, customizable chat widget that supports Light and Dark modes.
* **Lead Tracking:** View full conversation transcripts and summaries in your admin dashboard.
* **Smart Feedback:** Allows users to like/dislike responses, helping the AI learn from examples.

== Installation ==

1. Upload the `aica-intelliagent` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **AI Chat Agent > Settings** to configure your API keys.
4. Use the **Knowledge Base** tab to sync your website content.

== Frequently Asked Questions ==

= Does this require an API Key? =
Yes, you will need an API key from either OpenAI, Google AI Studio, or xAI (Grok) depending on which model you choose to use.

= Can it read my PDFs? =
Yes, the plugin includes a built-in PDF parser that extracts text from uploaded documents to provide context to the AI.
